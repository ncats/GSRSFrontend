What to include in an SD File

SD Files should represent drug substances, starting materials, intermediates, impurities, degradants, and leachables exceeding the Analytical Evaluation Threshold (AET). Reagents and solvents should be excluded.

Recommended data headers

Headers must be enclosed in angle brackets, for example > <NAME>. Using these exact names promotes an efficient review.

Key format requirements

  • Structure format must be V2000. V3000 is not accepted.
  • The MOL header must contain exactly three lines before the counts line (the line containing V2000). These lines may be blank.
  • Records must be separated by a line containing four dollar signs: $$$$.
  • The file extension must be .sdf or .txt.
  • Avoid special atom notations and S-groups where possible; see the Quick Guide for how to represent salts, stereochemistry and isotopes properly.
  • At least one record should be identified as the drug substance in its ROLE field.
